# IR-Jammer-Flipperzero

This flipper zero IR app uses the flipper zero's inferred transmitter to jam/block other IR signals from reaching a receiver.  

<img src="IR_jam.jpeg" alt="IR Jammer" width="300">

## -Menu
- Start-Allows you to start and stop the IR Jamming
- Settings-Allows you to configure many settings giving you full customisability over the jam.
- Info-Gives tips + tells you what each setting does.

## -Settings
- Mode-Changes from normal/auto mode to custom
- Freq-Allows you to change the frequency if the mode is cutsom
- Duty-Changeable duty
- MinPluse-Set the minimum IR pulse
- MaxPulse-Set the maximum IR pulse

## -How it works
The flipper will send off a large variety of powerful IR signals that have the goal of drowning out other weaker IR signals that get transmitted. This will block the signal causing it to be unable to reach any IR receivers. Note- when jamming, for best results aim the flippers IR emitter at either the remote you want to jam, or directly at the receiver, this allows you to have full control over what IR signals make it through.

## -Other info
- Red blinking LED = IR jamming is active
- App icon was made in pixl
- Range = about 3 meters

## -Why it was made
I wanted to use the flipper zero for IR jamming like on other IOT devices that run the Bruce firmware, but as it turned out there was no true IR jamming app for the flipper zero, so I decided to create this one that properly uses the flipper's powerful IR emitter to properly block other IR signals.
